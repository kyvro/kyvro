# 插件与 Codex 用量安全检查（2026-10-25）

范围：本次新增精确文件读取、Codex 用量插件、插件网络请求及详情视图边界。采用源码检查与本地模拟测试，未读取真实账号凭据或发起真实用量请求；不构成完整安全审计。

## 已修复

- 网络跳转可能转发插件自定义认证头：跨源（协议、域名或端口变化）移除所有插件提供的请求头、Authorization、Proxy-Authorization、Cookie 及 Referer。以初始请求源为参照，覆盖跨源后继续同源跳转时 Go 重新复制初始请求头的情况。HTTPS 降级跳转被拒绝，域名白名单仍逐跳检查。
- Codex 认证请求不需要跳转：增加通用 `followRedirects: false` 选项，返回原始 3xx，Codex 插件已使用。未成功的响应不会替换已有用量缓存。
- 底层网络异常可能含完整 URL 和敏感查询参数：创建请求、传输及响应读取错误改为固定诊断，不回显原始 URL 或底层错误。

## 已检查的边界

- 文件读取仅匹配声明的精确路径，使用 OpenRoot 限制父目录内解析，拒绝末级符号链接、目录、无效 UTF-8 和超过 2MiB 的文件，核对打开前后的文件身份。
- Codex 插件只请求固定 HTTPS 用量端点，不写入或刷新登录文件；缓存只保存展示字段，模拟 token 不进入缓存或展示错误。
- 详情页由受限组件树组成，Vue 文本插值不执行 HTML；组件数、深度与数据体积受限。事件须匹配当前随机会话 ID 和视图声明；禁用、重载或关闭后的会话不能继续操作。

## 尚存的限制

- 文件与网络权限沿用 manifest 声明即授权，没有逐项授权确认或升级新增权限确认。能读取登录文件的插件会拿到其中的原始凭据，当前安全模型要求信任插件代码。精确路径授权不等于凭据代理或防外传机制。
- 网络域名白名单未过滤私网地址、DNS 重绑定或限制端口。通用接口仍支持显式 HTTP 请求；Codex 插件固定使用 HTTPS。
- 文件父目录允许由操作系统解析链接；不能将本接口视为对抗本机恶意进程并发改写目录 / 文件的完整隔离。普通文件读取不提供独立的 I/O 取消机制。
- goja 插件与宿主同进程，调用超时和能力限制不是操作系统级隔离，也没有独立内存配额。

## 验证

Go vet、internal/service 单测、插件 race 检测、SDK TypeScript 检查及前端构建通过。回归覆盖跨源连续重定向时认证头和 Referer 不泄露、禁止跳转、错误不回显敏感 URL、精确文件越权拒绝、缓存不保存凭据及失效视图拒绝。
